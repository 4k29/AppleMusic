# Music Lens

Appleの「データとプライバシー」から取得したApple Music利用データを、自分のブラウザ内だけで読み込み、曲・アーティスト・アルバムのランキングや聴き方の傾向を確認する静的Webアプリです。

> **対応状況:** 現時点では実際のApple提供ファイルを確認できていません。Apple固有のファイル名・列名を推測せず、汎用CSVを列割り当てして取り込む初期版です。Apple形式への正式対応には匿名化した列名・日時形式・単位・行の意味の確認が必要です。

## データの入手と使い方

1. Appleの「データとプライバシー」ページで自分のデータのコピーをリクエストし、Apple Music関連データを取得します。
2. アプリで1つ以上のCSVを選ぶか、ドロップ領域へ移動します。
3. プレビューを確認し、各列を「曲名」「アーティスト」「アルバム」「再生日時」「実再生時間」「再生回数」「イベントID」に割り当てます。
4. 1行が再生イベントか曲ごとの累計か、時間単位、表示タイムゾーンを指定して取り込みます。
5. 期間・検索・指標を変更し、ランキング、日/月別傾向、曜日×時間帯を確認します。ランキングはCSV出力できます。

実ファイルを使わず試す場合は「デモで試す」を選びます。デモは明示された合成データで、実履歴を読み込むと置き換わります。

## 対応形式と制約

- UTF-8の汎用CSV（BOM、引用符、フィールド内改行、日本語、複数ファイルに対応）
- 1ファイル50MBまで。解析失敗とイベントID重複は取り込みレポートに表示します。
- イベント形式は1行を1再生、累計形式は指定した再生回数を使います。両形式を自動で合算・推測しません。
- 実再生時間がなければ総リスニング時間を表示しません。日時がなければ時系列とヒートマップを表示しません。
- ファイル間の重複はイベントIDがある場合だけ除外します。曲名と日時だけでは除外しません。
- 日時のタイムゾーン指定がない文字列はブラウザのJavaScript解釈に依存します。取り込み前に元データの仕様を確認してください。

## プライバシー、保存、削除

解析、集計、保存はブラウザ内で完結し、履歴をサーバー、アクセス解析、外部画像サービスへ送りません。「保存」はブラウザの `localStorage` を使うため、容量不足時はエラーを表示します。「全削除」で保存内容と表示中データを削除できます。ブラウザ自体のサイトデータ削除でも消去できます。

## 開発

Node.js 20以降を利用します。

```bash
npm install
npm run dev
npm test
npm run typecheck
npm run build
```

パーサー、正規化、集計、保存、画面を分離したReact + TypeScript + Vite構成です。テストデータはすべて合成値です。

## GitHub Pagesへの公開

Viteのbase pathは相対パスに設定済みです。`main` へのpush後、GitHub Actionsの **Test and deploy Pages** がテストとビルドを実行して `dist` をPagesへ公開します。リポジトリの Settings → Pages でSourceを **GitHub Actions** に設定してください。
